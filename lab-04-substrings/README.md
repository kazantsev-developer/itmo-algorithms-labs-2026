## Задание 2. Четыре алгоритма поиска подстрок

Строка из 500 простых чисел, склеенных без разделителей. Для каждого из 90 двузначных шаблонов считается частота вхождения. Все четыре алгоритма дают одинаковый ответ, максимум 73 вхождения у числа 31.

### 2.1 Наивный поиск

Прямое посимвольное сравнение шаблона с каждой позицией текста. Сложность O(n*m), память O(1). На коротком паттерне работает быстро.

![naive](img/02_naive_search.png)

### 2.2 Рабина-Карпа

Поиск через полиномиальный хэш скользящего окна. Хэш пересчитывается за O(1). Сложность O(n+m) в среднем.

![rabin](img/03_rabin_karp.png)

### 2.3 Бойера-Мура

Сравнение справа налево с эвристикой плохого символа. Сложность O(n/m) в лучшем случае. На коротких паттернах проигрывает.

![boyer](img/04_boyer_moore.png)

### 2.4 Кнута-Морриса-Пратта

Поиск через префикс-функцию без отката указателя по тексту. Гарантированная линейность O(n+m). Память O(m).

![kmp](img/05_kmp.png)
